# Security policy

## Reporting a vulnerability in this tool

Email rahilsahu.jobs@gmail.com with:

- A description of the issue and its impact
- Steps to reproduce, ideally with a minimal test case
- The version or commit you tested

Please give a reasonable window for a fix before disclosing publicly.
Reports are taken seriously and credited in the fix commit unless you
prefer to stay anonymous.

## Scope note

This tool is published for authorised security testing, defence and
learning. Vulnerabilities in third-party systems found while using it
are the responsibility of the tester to report to that system's owner.
